# Location UX source notes — 22 September 2026

The location workflow has been refocused around a three-step **trace → model → explain** path, following the public-facing interaction hierarchy visible at [SolarLLM](https://solarllm.app/). Its current landing copy emphasizes a roof trace from satellite imagery, a compact system model, and a clear result range rather than multiple competing configuration routes.

Selectable country polygons are derived from [datasets/geo-countries](https://github.com/datasets/geo-countries), a Natural Earth-derived GeoJSON package. Its repository states that the source is public-domain Natural Earth data and is available under the Open Data Commons Public Domain Dedication and License. The project stores compacted paths only for the supported UK, European, Canadian, and Japanese territories.
