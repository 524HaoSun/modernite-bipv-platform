# SolarLLM Interaction Reference

Source reviewed: [SolarLLM](https://solarllm.app/), accessed 22 September 2026.

The reference journey uses a persistent, numbered progress rail and presents one dominant action per step. Location begins with a compact postcode/address lookup and optional device location. Roof measurement then provides explicit draw mode, point count, a live polygon, area calculation, Undo and Finish/Cancel controls. The selected building form is represented by recognisable visual cards and paired with a 3D preview plus editable orientation and roof-pitch defaults.

Modernité will use these interaction principles without copying SolarLLM’s brand, visual identity, image assets, copy, or proprietary calculations. The redesign will preserve the Modernité visual system and will treat all maps, roof outlines, building categories, and BIPV materials as original application content.
